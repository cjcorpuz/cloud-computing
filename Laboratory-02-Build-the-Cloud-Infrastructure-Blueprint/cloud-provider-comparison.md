# Cloud Provider Comparison

Cloud providers provide similar infrastructure services, but each provider has its own service names and features. This comparison examines the core infrastructure services of Amazon Web Services (AWS), Microsoft Azure, and Google Cloud Platform (GCP).

## Infrastructure Service Comparison

| Infrastructure Component | AWS | Microsoft Azure | Google Cloud Platform |
|---|---|---|---|
| Compute | Amazon EC2 | Azure Virtual Machines | Compute Engine |
| Storage | Amazon S3 | Azure Blob Storage | Cloud Storage |
| Networking | Amazon VPC | Azure Virtual Network | Virtual Private Cloud (VPC) |
| Identity and Access Management (IAM) | AWS IAM | Microsoft Entra ID and Azure RBAC | Cloud IAM |

## Compute Services

AWS provides Amazon EC2, which allows users to create and run virtual servers for different applications and workloads. Azure provides Azure Virtual Machines for running Windows or Linux workloads, while Google Cloud provides Compute Engine for creating and managing virtual machine instances.

## Storage Services

Amazon S3 provides object storage for files, documents, backups, and other data. Azure Blob Storage is Microsoft's object storage service, while Google Cloud Storage provides scalable storage for data using buckets.

## Networking Services

Amazon VPC allows AWS resources to communicate through a logically isolated virtual network. Azure Virtual Network provides private networking for Azure resources, while Google Cloud VPC provides networking capabilities for virtual machines and other cloud services.

## Identity and Access Management

AWS IAM is used to control access to AWS resources through users, roles, and permissions. Microsoft Entra ID and Azure role-based access control help manage identities and permissions in Azure, while Google Cloud IAM controls access to Google Cloud resources based on assigned roles and permissions.

# Guide Questions

## 1. Which cloud provider offers the broadest range of services? Explain your answer.

AWS offers a very broad selection of cloud services for different computing and business requirements. Its services cover areas such as computing, storage, databases, networking, security, analytics, monitoring, and machine learning, giving organizations many options when designing cloud solutions.

## 2. Which cloud platform would you recommend for an organization that primarily uses Microsoft products? Why?

I would recommend Microsoft Azure for an organization that already relies heavily on Microsoft products. Azure provides integration with Microsoft technologies and supports services and workloads commonly used in Microsoft-based environments.

## 3. Which platform is widely recognized for Artificial Intelligence (AI), Machine Learning (ML), and Kubernetes services?

Google Cloud Platform is widely recognized for its capabilities in artificial intelligence, machine learning, and Kubernetes. Google is closely associated with Kubernetes and provides Google Kubernetes Engine (GKE), while also offering cloud services for developing and deploying AI and machine learning applications.

## 4. What similarities did you observe among the three cloud providers?

The three cloud providers offer similar fundamental infrastructure services, including compute, storage, networking, and identity and access management. They also provide scalable cloud resources, management tools, security features, and services that can support different types of applications and workloads.
