## 1. Brief Overview

Amazon Web Services (AWS) is a cloud computing platform launched in 2006. It provides different cloud capabilities and services that help organizations modernize their operations, support innovation, and secure their data. AWS is used by various organizations, including startups, enterprises, non-profits, and governments.

## 2. Global Infrastructure

AWS has a global infrastructure made up of geographic Regions and Availability Zones. A Region is a separate geographic area where AWS provides cloud resources, while Availability Zones are isolated locations within a Region. AWS also provides Local Zones and Wavelength Zones for specific applications and locations closer to end users. This infrastructure allows organizations to deploy applications in different locations and improve availability and fault tolerance.

## 3. Cloud Management Console

The AWS Management Console is a web-based interface used to access and manage AWS Cloud services and resources. It allows users to configure, monitor, and control different AWS services through a graphical interface without relying only on command-line tools.

## 4. Four Core Services

### Amazon EC2
Amazon EC2 provides virtual servers that can be used to run applications and workloads in the AWS Cloud.

### Amazon S3
Amazon S3 is an object storage service used to store and retrieve data such as files, images, and other objects.

### Amazon RDS
Amazon RDS is a managed relational database service that makes it easier to set up, operate, and scale relational databases.

### Amazon VPC
Amazon VPC allows users to create and manage an isolated virtual network for AWS resources.

## 5. Three Advantages

1. **Wide Range of Services** – AWS offers many cloud services that support computing, storage, databases, networking, security, analytics, and other business needs.

2. **Global Infrastructure** – AWS has infrastructure in different geographic locations, allowing organizations to deploy applications closer to their users and design systems for high availability.

3. **Scalability and Flexibility** – AWS allows organizations to adjust their cloud resources based on changing workloads and business requirements.

## 6. Typical Enterprise Use Cases

- **Application Hosting** – Enterprises use AWS to host websites, business applications, and other workloads without maintaining physical servers.

- **Data Storage and Backup** – Organizations use services such as Amazon S3 to store, back up, and retrieve large amounts of business data.

- **Database Management** – Enterprises can use managed database services such as Amazon RDS to run and manage relational databases.

- **Disaster Recovery** – AWS can help organizations maintain backup systems and recover applications and data when their primary infrastructure experiences disruptions.

- **Data Analytics** – Organizations use AWS services to collect, process, and analyze large amounts of data to support business decisions.
