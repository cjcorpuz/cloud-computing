# Mission Reflection

## 1. Which cloud platform impressed you the most?

Among AWS, Microsoft Azure, and Google Cloud Platform, AWS impressed me the most because of its wide range of cloud services and flexibility. I learned that AWS can support different types of workloads, from startups and web applications to large enterprise systems. Its services such as Amazon EC2, Amazon S3, Amazon RDS, and Amazon VPC provide organizations with different options for building cloud solutions.

## 2. What similarities exist among AWS, Azure, and GCP?

AWS, Microsoft Azure, and Google Cloud Platform provide similar core cloud services. All three platforms offer virtual machines for computing, object storage for storing data, database services, networking services, and identity management. They also provide scalable infrastructure that allows organizations to adjust resources based on their workload and business requirements.

## 3. How do business requirements influence cloud platform selection?

Business requirements are important when selecting a cloud platform because different organizations have different needs. For example, Microsoft Azure is a good choice for organizations that already use Microsoft technologies, while Google Cloud is a strong option for AI and Kubernetes workloads. AWS can be suitable for organizations that need a wide range of services and flexible cloud resources.

## 4. What did you learn from acting as a Cloud Solutions Consultant?

Acting as a Cloud Solutions Consultant taught me how to analyze a client's needs before recommending a cloud platform. I learned that choosing a cloud provider is not simply about selecting the most popular platform. The recommendation should consider factors such as existing technologies, scalability, workload requirements, and business goals.

## 5. How has your GitHub Cloud Computing Portfolio improved after completing this mission?

My GitHub Cloud Computing Portfolio has become more organized and informative after completing this mission. I added cloud platform comparisons, client recommendations, service matching tables, a multi-cloud decision matrix, and a Linux server investigation. These activities helped me demonstrate my understanding of cloud computing concepts and how they can be applied to real-world business scenarios.
