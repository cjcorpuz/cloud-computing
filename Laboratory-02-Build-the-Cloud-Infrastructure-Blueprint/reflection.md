# Mission Reflection

## What I Learned

In this laboratory, I learned how to identify and document the basic components of a cloud infrastructure. I was able to examine the compute, storage, networking, and operating system resources available in the KillerCoda environment.

I also learned how to use Linux commands to gather system information. Commands such as `lscpu`, `free -h`, `df -h`, and `ip addr` helped me identify the resources and network configuration of the virtual machine.

## Challenges Encountered

One challenge I encountered was understanding the information displayed by the Linux system commands. At first, some of the technical details such as the network interfaces, IP addresses, filesystem information, and CPU specifications were unfamiliar to me. I had to carefully examine the command results to identify which information was relevant to the laboratory requirements.

Another challenge was organizing the collected information into clear documentation. I learned that accurate documentation is important when designing or describing cloud infrastructure.

## Importance of Cloud Infrastructure

This laboratory helped me understand that cloud infrastructure is composed of different resources that work together. Compute resources provide processing power, storage provides space for data and system files, and networking allows systems and services to communicate. The operating system manages these resources and provides the environment where applications and services can run.

## Overall Reflection

Overall, the laboratory gave me a better understanding of how virtual cloud environments work. Using KillerCoda allowed me to work with a virtual machine and observe actual system resources instead of only reading about them. I also learned the importance of checking system information carefully and documenting the results accurately. This experience will help me understand cloud infrastructure concepts and apply them in future laboratory activities and projects.
