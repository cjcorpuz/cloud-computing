## 2. Questions and Answers

### 1. Which cloud provider offers the broadest range of services?

AWS offers the broadest range of cloud services among the three major cloud platforms. It provides a wide variety of services for computing, storage, databases, networking, security, analytics, and other business needs.

### 2. Which provider best integrates with Microsoft technologies?

Microsoft Azure best integrates with Microsoft technologies. It works well with products and services such as Windows Server, Microsoft 365, and SQL Server, making it a suitable choice for organizations already using Microsoft technologies.

### 3. Which provider is strongest in Artificial Intelligence and Kubernetes?

Google Cloud is a strong provider for Artificial Intelligence and Kubernetes. It offers advanced AI and machine learning capabilities and provides Google Kubernetes Engine (GKE) for managing containerized applications.

### 4. Which cloud platform would you personally choose and why?

I would personally choose AWS because it offers a broad range of cloud services and supports different types of workloads. I also find its services flexible and suitable for organizations with different cloud computing requirements.
