# Laboratory 02 – Build the Cloud Infrastructure Blueprint

## Overview

This laboratory focuses on identifying, documenting, and comparing the basic components of cloud infrastructure using a virtual machine environment provided by KillerCoda.

## Laboratory Objectives

* Identify the compute resources available in the virtual machine.
* Document storage and networking resources.
* Identify the operating system and system specifications.
* Compare major cloud service providers.
* Document the infrastructure information collected from the laboratory environment.
* Reflect on the learning experience and challenges encountered.

## Laboratory Files

### Cloud Infrastructure Components

`cloud-components.md`

Contains the identified compute, storage, networking, and operating system resources used in the laboratory.

### Cloud Provider Comparison

`cloud-provider-comparison.md`

Provides a comparison of Amazon Web Services (AWS), Microsoft Azure, and Google Cloud Platform (GCP).

### Infrastructure Report

`infrastructure-report.md`

Contains the actual system information collected from the KillerCoda Ubuntu virtual machine, including CPU, RAM, storage, network, and operating system details.

### Mission Reflection

`reflection.md`

Contains the reflection about the laboratory experience, lessons learned, and challenges encountered.

### Screenshots

The `screenshots` folder contains supporting screenshots from the laboratory activities.

## Environment

The laboratory was completed using the KillerCoda cloud-based virtual machine environment running Ubuntu 24.04.4 LTS.

## Summary

This laboratory provided practical experience in examining virtual cloud infrastructure resources and documenting system information. The activity helped develop a better understanding of compute, storage, networking, operating systems, and cloud service providers.
