# Mission 6: The Cloud Deployment Engineer

## Overview
This laboratory focuses on deploying a multi-tier cloud application using Docker Compose.

## Objectives
- Understand multi-tier application architecture.
- Create a Docker Compose configuration file.
- Deploy Nextcloud and MariaDB containers.
- Apply Infrastructure as Code (IaC) principles.
- Document the deployment process.

## Technologies Used
- Docker
- Docker Compose
- Nextcloud
- MariaDB
- GitHub
