# Laboratory 05 – Cloud Data Engineer

## Mission Overview

This laboratory activity focuses on cloud object storage using MinIO. A MinIO server will be deployed using Docker to simulate an S3-compatible cloud storage environment. The activity includes creating a storage bucket and uploading a sample file.

## Objectives

- Differentiate between Block, File, and Object Storage.
- Deploy an S3-compatible Object Storage server using MinIO and Docker.
- Access the MinIO cloud service through a web interface.
- Create a storage bucket and upload an object.
- Document cloud storage operations using Markdown.

## Tools Used

- KillerCoda Playground
- Ubuntu
- Docker
- MinIO
- GitHub
- Web Browser

## Skills Learned

- Understanding different types of cloud storage
- Deploying MinIO using Docker
- Using Docker environment variables
- Accessing services through forwarded ports
- Creating buckets and uploading objects
- Documenting cloud computing activities using Markdown
